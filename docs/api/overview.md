# API Overview

The Fairway REST API gives you programmatic access to every feature of the platform. Use it to create apps, trigger deployments, manage sandboxes, and query status — all from your own tooling or CI/CD pipelines.

**Base URL:** `https://api.pinhigh.ai/v1` *(placeholder)*
